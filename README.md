## 🇨🇳 中文

唇部彩妆 TVC 生成技能，用固定顺序把一支横屏唇部广告从零做完：先生成模特图，再生成 3×3 九宫格静物产品图，再写 30 秒分镜脚本，然后才生成视频分段，最后补背景音乐并合成校验。它解决的是唇部广告里模特一致性、产品一致性、贴字位置和单段返工四个高频痛点：模特图是人物身份主锚点，九宫格静物图是产品形式、包装、标签、刷头和质地的唯一生成依据，改哪一段就只重做那一段。适用口红、唇釉、唇泥、唇蜜、唇油等唇部品类，最终成片必须带背景音频，贴字只允许落在留白区。

### ✨ 能做什么

- 先生成模特图，锁定人物身份、灯光、构图与美妆风格
- 再生成 3×3 九宫格静物产品图，作为产品细节的唯一依据
- 写出 30s 分镜脚本：镜头顺序、时间段、产品卖点、贴字规则、结尾文案
- 三门锁校验：模特图 + 九宫格 + 最新脚本齐了才允许进入视频生成
- 30s 通常 7-8 镜、一镜一卖点，赶工时拆成 3 段模块化生成
- 必备证明镜头齐全（美妆特写/Hero/质地/上嘴显色/终版 packshot），自动补 BGM 并重出完整成片

## 🇬🇧 English

A lip-color TVC skill that builds a horizontal lip product commercial from scratch in a fixed order: model image first, then a 3x3 nine-grid still product image, then the 30-second storyboard script, only then video segments, and finally background music plus a compositing check. It targets the four recurring pain points of lip ads — model consistency, product consistency, caption placement, and redoing a single segment: the model image anchors identity, the nine-grid still is the sole source for product form, packaging, label position, applicator, and texture, and a redo replaces only the affected segment. It covers lipstick, lip gloss, lip tint, lip mud, and lip oil; the final cut must carry background audio, and captions may only sit in empty areas.

### ✨ What it does

- Generate the model image first to lock identity, lighting, framing, and makeup style
- Generate a 3x3 nine-grid still as the single source for product detail
- Write the 30s storyboard: shot order, time ranges, selling points, caption rules, end card
- Three-key gate: model image + nine-grid + latest script must all exist before video generation
- 30s runs as 7-8 shots, one selling point each, or 3 modular blocks under deadline
- Must-have proof shots (beauty close-up, hero, texture, on-lip color, final packshot), plus auto-added BGM and full re-export
